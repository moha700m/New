# Mohammed Lab PC

Clean-room Windows implementation by **Mohammed Lab** based on the observable workflow and settings of the supplied reference application.

## Pages
- Capture
- Game Control
- Guide
- Check

## Core settings
- Monitor, capture FPS, zone width/height
- No Preview, Show HUD
- Mouse / Controller mode
- Aim / Fire button binding
- Hold To Aim, Always Track
- Strength, Aim Point Offset
- Anti-Recoil, Auto Fire
- BO7 / BO6 / MW / MW4 / Overwatch game selection
- Controller test / replug and system checks

## Build
GitHub Actions publishes a self-contained Windows x64 artifact containing a single `MohammedLab-PC.exe`.

This repository does not include proprietary source code or branded assets from the reference application.
