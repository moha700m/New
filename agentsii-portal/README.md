# Agentsii — Customer Balance Portal

بوابة عربية (RTL) لإدارة وعرض أرصدة عملاء **Agentsii**.
مبنية بـ Next.js و TypeScript و Tailwind CSS، وتُخزَّن البيانات في **Vercel Blob** فقط، دون أي قاعدة بيانات خارجية.

## الميزات

**لوحة الإدارة** (`/admin`):
- إضافة عميل: الاسم، ورقم العميل، ورمز PIN، والرصيد الافتتاحي، والعملة.
- تعيين الرصيد بأي قيمة (بما فيها السالبة)، أو إضافة مبلغ، أو خصمه، مع ملاحظة لكل عملية.
- تعديل الاسم ورقم العميل والعملة.
- إيقاف الحساب وتفعيله، وتغيير رمز PIN، وإلغاء قفل تسجيل الدخول.
- حذف العميل نهائياً بعد كتابة رقمه للتأكيد.
- عرض جميع الأرصدة مع البحث والفلترة والإحصائيات، وسجل آخر 50 حركة لكل عميل.

**صفحة العميل** (`/`، ثم `/balance`): يدخل العميل رقمه ورمز PIN، فيرى اسمه ورقمه ورصيده المتبقي وتاريخ آخر تحديث للرصيد.

## الأمان

- كل القراءة والكتابة تتم على الخادم فقط، عبر Server Actions و Server Components. المتصفح لا يتصل بـ Blob إطلاقاً.
- ملف البيانات مخزَّن بصلاحية **private**، فلا يمكن فتحه برابط عام.
- رموز PIN محفوظة بتشفير scrypt مع salt، ولا تُخزَّن كنص.
- الجلسات في كوكيز موقّعة بـ HMAC، بخصائص `HttpOnly` و `Secure` و `SameSite=Strict`. جلسة الإدارة مدتها 8 ساعات، وجلسة العميل 15 دقيقة.
- يُقفل دخول العميل 15 دقيقة بعد 5 محاولات PIN خاطئة، مع حد لعدد المحاولات لكل عنوان IP.
- الرسالة واحدة عند الخطأ في رقم العميل أو في PIN، حتى لا يُعرف أي الأرقام موجود.
- إيقاف الحساب أو تغيير PIN أو تغيير رقم العميل يُنهي جلسة العميل فوراً.
- تغيير `ADMIN_PASSWORD` يُنهي جميع جلسات الإدارة.
- القراءة من Blob تتجاوز الكاش (`useCache: false`)، والكتابة مشروطة بالـ ETag (`ifMatch`) مع إعادة المحاولة، فلا تضيع أي تعديلات متزامنة.
- رؤوس أمان مفعّلة: HSTS و X-Frame-Options و nosniff، مع `no-store` لصفحات الإدارة والرصيد.

## النشر على Vercel

1. استورد المستودع في Vercel، واجعل **Root Directory** هو `agentsii-portal`.
2. من **Storage**، أنشئ Blob Store واربطه بالمشروع، فيُضاف `BLOB_READ_WRITE_TOKEN` تلقائياً.
3. أضف متغيرات البيئة التالية في **Settings → Environment Variables**:

| المتغير | الوصف |
| --- | --- |
| `ADMIN_PASSWORD` | كلمة مرور لوحة الإدارة (12 حرفاً على الأقل). |
| `SESSION_SECRET` | نص عشوائي من 32 حرفاً على الأقل، ويمكن توليده بالأمر `openssl rand -base64 48`. |
| `DEFAULT_CURRENCY` | اختياري. العملة الافتراضية للعملاء الجدد (`USD` افتراضياً). |
| `APP_TIMEZONE` | اختياري. المنطقة الزمنية لعرض التواريخ (`Asia/Riyadh` افتراضياً). |

4. أعد النشر (Redeploy).

## التشغيل محلياً

```bash
cd agentsii-portal
npm install
cp .env.example .env.local   # ثم عدّل القيم
npm run dev
```

عند التشغيل محلياً بدون `BLOB_READ_WRITE_TOKEN` تُحفظ البيانات في `.data/database.json`، وهذا مسموح في وضع التطوير فقط. في الإنتاج يرفض التطبيق العمل بدون Vercel Blob.
