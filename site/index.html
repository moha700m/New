ابدأ في 3 خطواتGet started in 3 steps

  1. ثبّت البرنامج — إن ظهر تحذير SmartScreen اضغط «More info» ثم «Run anyway».
  2. Install the app — if SmartScreen appears, click “More info” then “Run anyway”.
  3. Add Provider — اختر المزود، الصق مفتاح API، واختر الموديل.
  4. Add Provider — pick your provider, paste the API key, choose a model.
  5. Save & Connect to Codex — ثم أعد تشغيل Codex. انتهى!
  6. Save & Connect to Codex — then restart Codex. Done!
